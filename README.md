# siporacompany

## Local development

Run `npm run dev`, then open http://127.0.0.1:3000. The local server serves the site and its `/api` routes together. Products and orders are saved as JSON files in `data/` and persist across restarts.

Use the Vercel deployment for shared, production data; configure `BLOB_READ_WRITE_TOKEN` as described in `VERCEL_SETUP.txt`.
